## ✨ Features

### Customer
- Submit feedback with name, email, and message
- View submitted feedback
- Edit your own feedback
- Ownership-based edit protection

### Admin
- Secure admin login
- View all feedback
- Search by keyword
- Filter by date
- Delete feedback with confirmation

## 🛠️ Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Bootstrap
- JWT Authentication
- Vercel
- Render
